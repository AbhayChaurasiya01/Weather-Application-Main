# 🌤️ Weather Application

A simple and responsive **Weather Application** that provides real-time weather information for a selected location. The application uses a weather API to fetch and display accurate weather data in an easy-to-understand interface.

## 🚀 Features

* 🌍 Search weather by city/location
* 🌡️ Displays current temperature
* ☁️ Shows current weather conditions
* 💧 Displays humidity
* 💨 Shows wind speed
* 📍 Location-based weather information
* 📱 Responsive and user-friendly design
* 🔄 Real-time weather data using API

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and API integration
* **Weather API** – Fetching real-time weather information

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/AbhayChaurasiya01/Weather-Application-Main.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🌦️

## 🔑 API Configuration

If the project uses an API key, add your API key in the JavaScript configuration:

```javascript
const API_KEY = "YOUR_API_KEY";
```

> ⚠️ Do not upload your actual API key to a public GitHub repository. Use environment variables or another secure method for production projects.
